# Heartrot

**A vocal plugin for FL Studio (VST3, Windows) made for emo rap, trap metal, phonk and underground vocals.** By MXDVSA.

Heartrot is in **public beta** (versions 0.9.x). It is free while in beta.

> Heartrot was called *Vengeance* until version 0.9.5. Same plugin, new name.

## Download

Get the newest installer from the **[latest release](https://github.com/MXDVSA/heartrot-releases/releases/latest)**: the file is called `Heartrot-Setup-x.y.z.exe`.

## What it does

- **ANALYZE**: listens to your take and sets the EQ, de-esser, compressor, level ride and dynamic EQ for it. **WHY?** explains every move, **A/B** compares at matched loudness, **REVERT** undoes it.
- **Presets**: over 50 starting points in families (Clean Slate, Emo Rap, Trap Metal, Phonk / Drift, Rage / Underground, Adlibs / Doubles, Underworld, Studio Chains), plus your own saved presets and favourites.
- **Tone Match**: load a finished vocal you like (REF) and Heartrot nudges your take's tone toward it.
- **Everything in one window**: 8-band EQ, two-stage compression, de-esser, saturation, lo-fi, gate, reverb, tempo-synced delay, stereo width.

Heartrot has **no pitch correction**. For hard-tuned styles, put a pitch corrector (Auto-Tune, FL Studio's Pitcher, MAutoPitch, Graillon) before it in the mixer slot.

## Install

1. Close FL Studio.
2. Run `Heartrot-Setup-x.y.z.exe`. Windows may say **"Windows protected your PC"** because the installer isn't code-signed: click **More info**, then **Run anyway**.
3. In FL Studio open **Options > Manage plugins** and click **Find more plugins**. Heartrot shows up under installed VST3 effects.

**Needs:** 64-bit Windows and a VST3 host. It is built for FL Studio. The installer can also add a standalone Heartrot app.

**Coming from Vengeance?** Your presets, favourites and settings are copied over the first time Heartrot starts. Old FL projects that used Vengeance need Heartrot inserted once by hand, because FL Studio finds plugins by name.

## Updates

Heartrot checks this page for a newer version and tells you in its window when there is one. For that it asks GitHub's public API which release is the latest. It sends no information about you, your computer or your music. You can check by hand any time from the size button (100%) menu.
